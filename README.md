A comprehensive personal productivity PWA for:
- 🎓 PhD Research at Shiv Nadar University (SNU)
- 🏛️ Government Career Radar (DRDO/ISRO/NIC/TNPSC)
- 🚨 Claude CCDV-F Certification (Aug 31, 2026)
- 📋 UGC NET CS December 2026
- 💼 TCS Office Tracker with Follow-Up Board
- ❤️ Health & Medicine Tracker (PIN-protected)
- 📓 Daily Journal (PIN-protected)
- 🤖 AI Life Agent + PhD Advisor + Advice Buddy

## Deploy

```bash
npm install
npm run dev      # Local development
npm run build    # Production build
```

Deploy to Vercel: Connect this GitHub repo at vercel.com

## Update

Replace src/App.jsx with new version from Claude → git push → auto-deploys in 30 seconds.

## Install on Phone

1. Open your Vercel URL in Chrome (Android) or Safari (iPhone)
2. Android: Menu → "Add to Home Screen"
3. iPhone: Share → "Add to Home Screen"
