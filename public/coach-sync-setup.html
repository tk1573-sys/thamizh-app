Life Command Centre → Thamizh Life Coach

Configure the connection between your two separate apps. Nothing is shared until you enable publishing and save your choices.

This setup page does not add a companion panel to the Life Command Centre. It only manages an explicit data-sharing permission.

1. Secure connection

Use the same long random token in your Vercel environment variable LIFE_COACH_SYNC_TOKEN and in the Windows Life Coach's Life Plan Sync settings. Don't paste this token into chats or commit it to GitHub.

The token is saved only in this browser's localStorage. Access is limited to the matching authenticated endpoint. If this is a shared/public computer, do not save it here.

2. What the coach is allowed to know

These goal statements are shared only when “Goals I add in this setup page” is checked below.

3. Select the plan categories to share

These are independent switches. You can disable any category while keeping the connection active. Raw Health and Journal logs are never sent.

No sharing configuration saved yet.
